# Android 0.9 Beta SDK (Archival & Preservation)

Benvenuto! Questo repository contiene l'SDK originale di **Android 0.9 Beta**, rilasciato ad agosto 2008. Questo file è stato preservato per scopi storici, di studio e di emulazione dell'archeologia software di Android.

---

## ⚠️ Important Warning / Attenzione

*   **ENG:** **NOT FOR FLASHING!** This is a Windows SDK tool from 2008. It is **NOT** a custom ROM and cannot be flashed onto any modern smartphone or Android device. Doing so may brick your device.
*   **ITA:** **NON DA FLASHARE!** Questo è un tool SDK per Windows del 2008. **NON** è una ROM personalizzata e non può essere installata su nessuno smartphone. Usarlo su un telefono reale rischia di danneggiarlo permanentemente.

---

## 🛠️ How to run the historical Emulator on Windows

To run the original 2008 Android Emulator from this SDK, follow these steps on your PC:

1. **Download and Extract:** Download the `android-sdk-windows-0.9_beta.zip` from the Releases section and extract it to a folder (e.g., `C:\Android-SDK-0.9`).
2. **Java Requirement:** This software is from 2008 and is **not compatible** with modern Java versions (like Java 11, 17, or 21). You must install an old version like **Java Runtime Environment (JRE) 5 or 6** on your system.
3. **Launch via Command Prompt:**
   * Open the Windows Command Prompt (`cmd`).
   * Navigate to the `tools` directory inside the extracted folder:
     ```bash
     cd C:\Android-SDK-0.9\tools
     ```
   * Start the emulator by running:
     ```bash
     emulator.exe
     ```

This repository aims to preserve the early history of the Android Operating System before its official commercial release (Android 1.0) on the HTC Dream.
